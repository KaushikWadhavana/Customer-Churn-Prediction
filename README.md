
# Customer Churn Prediction Model with Dashboard

## 📌 Project Overview
This project uses machine learning to predict customer churn, analyze customer behavior, and visualize insights through an interactive Power BI dashboard.

## 💼 Business Problem
Customer churn can lead to revenue loss and increased customer acquisition costs. Businesses need to identify customers who may leave and understand the factors influencing their decisions.

## 💡 Solution
This project analyzes customer data and applies machine learning classification models to predict potential churn. A Power BI dashboard presents key insights to support data-driven decisions and customer retention strategies.

## 🎯 Objectives
- Clean and analyze customer data.
- Perform Exploratory Data Analysis (EDA) and feature engineering.
- Train and compare machine learning models.
- Predict customer churn and evaluate model performance.
- Analyze customer charges and visualize insights.

## 🛠️ Technologies Used
- **Programming:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Machine Learning:** Classification Models
- **Dashboard:** Microsoft Power BI
- **Tools:** Jupyter Notebook, Git, GitHub
